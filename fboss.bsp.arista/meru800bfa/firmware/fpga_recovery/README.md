To perform the FPGA recovery:
    - Copy recover_whistler_fpgas.zip to the meru800bfa system and unzip it
    - Go to the `recover_whistler_fpgas` directory
    - Do `chmod +x recover_fpgas.sh`
    - Run the script as `./recover_fpgas.sh`

flashrom needs to be installed on the meru800bfa system for the recovery script to work
